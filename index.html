The studio

About

Waking Horizon is a one-person game studio based in Finland, building top-down action games in dark fantasy worlds.

Easy to start, hard to master. Every game is built to feel good in the hands first, with the fun up front and deep, emerging systems to follow. The current focus is top-down 3D action RPGs, with more worlds waiting beyond the horizon.

Formerly known as Shifting Reality Interactive. Same developer, same games, new name.
